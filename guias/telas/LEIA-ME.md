# Prints das telas — o que capturar

Os guias já funcionam sem imagem: onde falta o print, aparece uma caixa
pontilhada dizendo qual arquivo colocar. **Assim que você salvar o arquivo
nesta pasta com o nome certo, a imagem aparece sozinha** — não precisa editar
nenhum HTML.

## Como tirar

Faça o percurso **no seu próprio celular**, como se você fosse a pessoa da
oficina, e capture cada tela listada abaixo.

- **Android:** segurar `Power` + `Volume para baixo`
- **iPhone:** segurar `Power` + `Volume para cima`

Salve os arquivos nesta pasta (`guias/telas/`) com exatamente o nome indicado,
em `.png`.

## ⚠️ Antes de capturar, tape seus dados

Você vai estar logado na sua conta. Antes de salvar, **cubra com um retângulo
preto** (o editor de imagem do próprio celular faz isso):

- Seu CPF
- Seu nome completo
- Sua data de nascimento
- Qualquer número de documento, protocolo ou cartão do SUS

O print serve para mostrar **onde ficam os botões**, não os seus dados. Isso vai
para um repositório público no GitHub.

## Enquanto captura, confira o texto

Os sites do governo mudam de layout com frequência, e os guias foram escritos
descrevendo o que se espera encontrar. Se alguma tela estiver diferente do que
o guia diz — outro nome de botão, um passo a mais, uma ordem trocada — anote e
me avise, que eu ajusto o texto para bater com o que você viu.

Guia que descreve tela errada atrapalha mais do que ajuda.

## Bônus

Esses prints também servem como **evidência de desenvolvimento** no trabalho
final: mostram que o material foi construído a partir do percurso real, e não
copiado de algum lugar.
